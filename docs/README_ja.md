# DomainShifter - マルチ天気スタイル転送自動化プラットフォーム

> [English Documentation](../README.md) | [中文文档](./README_zh.md)

複数のModel Context Protocol（MCP）サーバーを活用して、シームレスなマルチ天気ドメインシフトとニューラルスタイル転送ワークフローを実現するインテリジェント自動化プラットフォーム。堅牢なエージェント機能と包括的な自己チェック機能を備えています。

## 概要

DomainShifterは**マルチ天気ドメインシフトとニューラルスタイル転送**操作に特化した専門的な自動化プラットフォームです。異なる転送プロトコル（stdioとHTTP）を介して複数のMCPサーバーを統合することで、天気ベースのシームレスなドメイン適応と芸術的スタイル変換ワークフローを実現します。

### コアミッション
高度なニューラルスタイル転送技術により、セマンティックな一貫性と芸術的品質を維持しながら、異なる天気ドメイン（晴天 ↔ 雨天 ↔ 雪天 ↔ 霧天）間で視覚コンテンツを変換します。

### 天気ドメインシフト
- **自動天気検出**: 入力画像内の天気条件のインテリジェント認識
- **マルチドメイン適応**: 異なる天気シナリオ間のシームレスな変換
- **スタイル認識転送**: 天気ドメイン間でのコンテキスト保持ニューラルスタイル転送
- **バッチ処理**: 大規模な天気ドメイン変換タスクの効率的な処理

## 主要機能

### 天気ドメイン転送エンジン
- **晴天からXへの変換**: 晴天シーンを雨天、雪天、霧天条件に変換
- **雨効果合成**: 適切な照明と反射を伴うリアルな雨効果生成
- **雪生成**: 深度と大気効果を持つ自然な雪被覆
- **霧シミュレーション**: 距離ベースの可視性を持つ大気霧レンダリング
- **双方向転送**: あらゆる天気ドメイン間の変換をサポート

### ニューラルスタイル転送統合
- **芸術的スタイル適応**: 天気特性を保持しながら芸術的スタイルを適用
- **天気認識スタイリング**: 天気固有の照明と大気効果を尊重するスタイル転送
- **GPU加速処理**: リモートGPUクラスターでの高性能ニューラルネットワーク推論
- **マルチ解像度サポート**: サムネイルから高解像度形式まで画像を処理

### 🔗 マルチトランスポートMCP統合
- **📡 ローカルサーバー**: stdio転送プロトコル経由でローカルMCPサーバーに接続
- **🌐 リモートGPUサービス**: HTTP経由でリモートGPU駆動スタイル転送サーバーに接続
- **🎯 統一インターフェース**: 単一の`MultiServerMCPClient`がすべての接続タイプを処理
- **🛡️ グレースフルな劣化**: サーバーが利用できない場合の自動フォールバック

### 🤖 インテリジェントエージェントシステム
- **🧠 ReActエージェント**: 複雑なワークフローのための推論と行動能力を持つインタラクティブエージェント
- **🏗️ 構造化データ処理**: タイプセーフな天気とスタイルメタデータ処理にPydanticモデルを使用
- **🔄 LLM駆動パース**: 非構造化ツール出力を構造化データに自動変換
- **⚡ 堅牢なエラー処理**: 一部のサービスが失敗しても実行を継続

### 🔍 自己チェックと診断
- **✅ 起動時検証**: 設定されたすべてのMCPサーバーの自動検証
- **📈 ヘルス監視**: リアルタイムステータスチェックと詳細レポート
- **🔄 フォールバック戦略**: プライマリサービスが利用できない場合のインテリジェントなツール選択

### 🤖 柔軟なLLMサポート
- **🏢 複数プロバイダー**: OpenAI、Anthropic、Google、DeepSeek、XAIモデルのサポート
- **🔄 動的モデル切り替え**: ランタイム中のモデル変更
- **⚙️ 設定駆動**: JSONベースのモデルとサーバー設定

## 🏗️ アーキテクチャ

### 🔧 コアコンポーネント

- **`mcp_client_manager.py`**: フォールバック機能付きの堅牢なMCPクライアント
- **`llm_manager.py`**: 複数プロバイダーをサポートする統一LLMインターフェース

- **`run_agent.py`**: 自己チェック機能付きのインタラクティブReActエージェント

### 📁 MCPサーバー構造

ローカルMCPサーバーは構造化されたパッケージレイアウトに従います：
```
mcp_servers/
├── general/
│   ├── __init__.py
│   ├── __main__.py
│   └── server.py
└── remote_file_explorer/
    ├── __init__.py
    ├── __main__.py
    └── server.py
```

### ⚙️ 設定ファイル

- **`mcp.json`**: MCPサーバー設定（stdioとHTTP転送）
- **`models.json`**: 利用可能なLLMモデルとその識別子
- **`.env`**: APIキーと環境変数

## 🚀 使用方法

### 📋 前提条件

```bash
# uvを使用して依存関係をインストール
uv sync

# 仮想環境をアクティベート
source .venv/bin/activate
```



### 💬 インタラクティブエージェントモード

ReActエージェントとのインタラクティブチャットセッションを開始：

```bash
python run_agent.py
```

エージェントは以下を実行します：
1. 🔍 設定されたすべてのMCPサーバーで自己チェックを実行
2. 📊 接続ステータスと利用可能なツールを報告
3. 🗣️ ユーザークエリのインタラクティブモードに入る

### ⚙️ 設定

#### MCPサーバー (`mcp.json`)
```json
{
  "mcpServers": {
    "local-server": {
      "command": "{PROJECT_ROOT}/.venv/bin/python",
      "args": ["-m", "domainshifter.mcp_servers.general"],
      "transport": "stdio"
    },
    "remote-service": {
      "url": "http://remote-host:3000/mcp",
      "transport": "streamable_http"
    }
  }
}
```

#### モデル (`models.json`)
```json
[
  {
    "name": "Claude Sonnet 4",
    "id": "claude-sonnet-4-20250514"
  },
  {
    "name": "GPT-4o",
    "id": "gpt-4o"
  }
]
```

## リモートGPUサービス

プラットフォームは集約的な計算タスクのために専用のGPU駆動リモートサービスを活用します：

### 🏭 天気ドメイン転送サービス
- **🌈 天気変換エンジン**: 高性能天気ドメイン変換
- **🎨 スタイル転送クラスター**: 分散ニューラルスタイル転送処理
- **🔄 バッチ処理パイプライン**: 大規模画像データセットのスケーラブル処理
- **📊 リアルタイム監視**: ライブステータスとパフォーマンスメトリクス

### 🛠️ サービスインフラストラクチャ
- **⚡ GPU加速**: リアルタイム処理用のCUDA最適化推論
- **🌐 Tailscaleネットワーキング**: セキュアなクロスネットワーク接続
- **🔄 ロードバランシング**: 利用可能なGPUノード間での自動分散
- **📈 オートスケーリング**: ワークロードに基づく動的リソース割り当て

### 🎯 専門サービス
- **LocalWeatherService**: コンテキスト認識処理のためのリアルタイム天気データ統合
- **StyleTransferService**: 天気保持機能付き高度ニューラルスタイル転送
- **SnowGenerationService**: 専門的な雪効果合成とアプリケーション

> **注記**: これらのGPU駆動サービスは、ローカルハードウェアでは計算集約的なリアルタイム天気ドメインシフトとスタイル転送操作を可能にします。

## エラー処理と堅牢性

- **⏰ 接続タイムアウト**: 利用できないサービスでのハングを防ぐ設定可能なタイムアウト
- **🔄 グレースフルな劣化**: 利用可能なサーバーでシステムが動作を継続
- **🔀 フォールバックツール**: プライマリツールが失敗した場合の代替ツールの自動選択
- **📝 包括的ログ**: デバッグ用の詳細ステータスレポート
